# Notifikasi & Riwayat Pengajuan - Panduan Pengguna

## Apa itu Notifikasi & Riwayat Pengajuan?

Setelah Anda mengajukan surat keterangan, admin desa akan memeriksa berkas Anda. Fitur ini memberi tahu Anda setiap kali status pengajuan berubah (misalnya sedang diproses, disetujui, atau ditolak) melalui **notifikasi in-app**, tanpa perlu datang ke kantor desa. Anda juga dapat melihat **riwayat lengkap** semua pengajuan dan membuka **detail** setiap pengajuan.

## Cara Menggunakan

### Melihat Notifikasi Baru

1. Masuk sebagai **warga** dan buka halaman mana pun setelah login (Dashboard, Riwayat, dll.).
2. Di bagian bawah **sidebar** (menu kiri), klik ikon **lonceng** di atas menu profil Anda.
3. Jika ada notifikasi belum dibaca, angka merah akan muncul di ikon lonceng.
4. Daftar notifikasi terbaru ditampilkan di dropdown. Item yang belum dibaca tampil lebih tebal/berlatar berbeda.

> 💡 **Tips:** Daftar notifikasi diperbarui otomatis setiap ±30 detik tanpa perlu me-refresh halaman.

### Membuka Notifikasi & Melihat Detail Pengajuan

1. Klik salah satu notifikasi di dropdown.
2. Notifikasi otomatis ditandai **sudah dibaca**.
3. Anda diarahkan ke halaman **Detail Pengajuan** yang berisi:
   - Jenis surat, tanggal, status
   - Keperluan pengajuan
   - Catatan admin (jika pengajuan **ditolak**)
   - Daftar dokumen yang pernah diunggah
4. Klik **Kembali ke Riwayat** untuk kembali ke daftar pengajuan.

### Memantau Riwayat & Status Pengajuan

1. Buka menu **Riwayat Pengajuan** di sidebar.
2. Tabel menampilkan: nomor pengajuan, jenis surat, tanggal, status, dan catatan admin (jika ditolak).
3. Gunakan **Filter Status** untuk menampilkan hanya pengajuan dengan status tertentu (Diajukan, Disetujui, Diproses, Siap Diambil, Selesai, Ditolak).
4. Klik tombol **Detail** pada baris untuk melihat informasi lengkap pengajuan tersebut.
5. Jika status **Ditolak**, tombol **Ajukan Ulang** tersedia di tabel maupun halaman detail.

## FAQ

**Q: Kapan saya menerima notifikasi?**
A: Saat pengajuan *Disetujui* (lalu *sedang diproses*), atau saat *Ditolak* dengan catatan admin. Membuka detail oleh admin saja **tidak** memicu notifikasi.

**Q: Apakah notifikasi dikirim lewat WhatsApp?**
A: Tidak. Saat ini hanya notifikasi di dalam aplikasi (in-app).

**Q: Bagaimana jika notifikasi menumpuk?**
A: Dropdown menampilkan notifikasi terbaru dengan pagination (*Sebelumnya* / *Berikutnya*) jika jumlahnya banyak.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Badge tidak muncul padahal admin sudah memproses | Tunggu ±30 detik atau buka ulang dropdown lonceng; pastikan Anda login sebagai warga pemohon |
| Tidak bisa buka detail pengajuan orang lain | Normal — Anda hanya dapat melihat pengajuan milik akun Anda sendiri |
| Catatan admin kosong | Catatan hanya ditampilkan jika pengajuan ditolak oleh admin |
