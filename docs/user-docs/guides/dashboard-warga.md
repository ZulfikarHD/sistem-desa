# Dashboard Warga - Panduan Pengguna

## Apa itu Dashboard Warga?

Halaman pertama setelah Anda masuk sebagai warga. Fokus utamanya menjawab: **“Sudah sampai mana surat saya?”**

## Cara Menggunakan

### Melihat status pengajuan aktif

1. Masuk dengan akun warga — Anda diarahkan ke **Dashboard Warga**.
2. Kartu besar di bagian atas menampilkan:
   - Jenis surat dan nomor pengajuan
   - Status (Diajukan / Diproses / Siap Diambil)
   - Penjelasan singkat dalam bahasa sehari-hari
   - Berapa hari sudah di status tersebut
3. Jika status **Diproses** atau **Siap Diambil**, gunakan tombol **Unduh Surat**.
4. Jika **Siap Diambil**, perhatikan tanggal dan jam kerja pengambilan yang ditampilkan besar.

### Jika belum ada pengajuan aktif

1. Anda akan melihat pesan ramah dan tombol **Ajukan Surat Sekarang**.
2. Klik tombol tersebut untuk mulai pengajuan.

### Ajukan surat baru

1. Jika sudah ada pengajuan aktif, tombol **Ajukan Surat Baru** tetap ada di bawah kartu status (tidak menutupi status).

### Riwayat dan notifikasi

1. Bagian **Riwayat Terbaru** menampilkan 3 pengajuan terakhir. Klik **Lihat Semua Riwayat** untuk daftar lengkap.
2. Bagian **Notifikasi Terbaru** menampilkan 3 notifikasi (yang belum dibaca diutamakan). Titik merah = belum dibaca.
3. Jika ada notifikasi baru, banner di atas halaman juga memberi tahu. Klik **Lihat notifikasi** / **Lihat Semua Notifikasi** untuk membuka panel lonceng.

> 💡 **Tips:** Jika status masih “Diajukan” lebih dari seminggu, teks hari akan berwarna kuning sebagai pengingat untuk menghubungi kantor desa bila perlu.

## FAQ

**Q: Kenapa saya tidak melihat unduh surat?**
A: Tombol unduh hanya muncul jika surat sudah digenerate (status Diproses / Siap Diambil / Selesai).

**Q: Bisa melihat pengajuan orang lain?**
A: Tidak. Dashboard hanya menampilkan data milik akun Anda.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Banner notifikasi tidak hilang | Buka panel lonceng dan klik notifikasi agar ditandai dibaca |
| Jadwal pengambilan tidak muncul | Pastikan status sudah Siap Diambil; hubungi petugas jika tanggal belum diisi |
