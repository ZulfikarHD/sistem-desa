# Pengaturan Desa - Panduan Pengguna (Admin)

> **Kelompok Pengguna:** Admin / Petugas Desa
> **Urutan:** 3 dari 17 — Atur identitas kantor (kop bukti pengambilan) sebelum memproses surat.

## Apa itu Pengaturan Desa?

Halaman ini menyimpan nama desa, kecamatan, kabupaten, alamat, telepon, dan kode nomor surat yang muncul pada **Bukti Pengambilan Berkas**. Jam kerja dan daftar libur nasional diatur di konfigurasi sistem (bukan di halaman ini).

## Cara Menggunakan

1. Masuk sebagai **admin**.
2. Di sidebar, klik **Pengaturan Desa**.
3. Isi identitas kantor dan kode nomor surat.
4. Klik **Simpan Pengaturan**.

> 💡 **Tips:** Nama penandatangan disimpan untuk arsip administrasi; bukti pengambilan tidak mencetak tanda tangan Kepala Desa.

## FAQ

**Q: Apakah mengubah pengaturan mengubah PDF lama?**
A: PDF yang sudah diunduh tidak berubah otomatis. Unduh ulang / regenerate memakai data terbaru jika file digenerate ulang.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Tidak melihat menu | Pastikan akun role admin |
| Validasi gagal | Nama desa, kecamatan, kabupaten, alamat, dan kode wajib diisi |
