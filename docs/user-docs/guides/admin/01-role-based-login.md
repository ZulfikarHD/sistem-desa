# Login Berbasis Role - Panduan Pengguna (Admin)

> **Kelompok Pengguna:** Admin / Petugas Desa
> **Urutan:** 1 dari 17 — Langkah pertama untuk masuk ke sistem admin.

## Apa itu Login Berbasis Role?

Setelah punya akun admin, Anda masuk dengan **email** dan **password**. Sistem mengenali bahwa Anda adalah **admin/petugas desa**, lalu membuka **Dashboard Admin** secara otomatis.

## Cara Menggunakan

### Masuk sebagai admin

1. Buka halaman **Masuk** (`/login`), atau dari beranda klik **Masuk**.
2. Isi form:
   - **Email**: email akun admin Anda
   - **Password**: password akun Anda
3. (Opsional) centang **Ingat saya** agar sesi lebih tahan lama di perangkat ini.
4. Klik **Masuk**.
5. Anda diarahkan ke **Dashboard Admin**.

> 💡 **Tips:** Akun admin dibuat oleh petugas IT/sistem, tidak bisa didaftarkan sendiri lewat form registrasi publik.

### Keluar (logout)

1. Dari dashboard, buka menu profil di sidebar (nama/avatar Anda).
2. Klik **Keluar**.
3. Anda kembali ke beranda dan harus masuk lagi untuk membuka dashboard.

### Jika login gagal

- Pastikan email dan password benar.
- Pesan error bersifat umum demi keamanan.
- Jika lupa password, gunakan tautan **Lupa Password?** di form login. Panduan: [Lupa Password](15-password-reset.md).

## FAQ

**Q: Mengapa saya tidak masuk ke Dashboard Admin?**
A: Pastikan Anda login dengan akun berstatus admin, bukan warga. Dashboard mengikuti **role** akun.

**Q: Bisakah saya mendaftar sebagai admin lewat form registrasi?**
A: Tidak. Akun admin dibuat oleh petugas IT, bukan melalui form publik.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Pesan kredensial tidak cocok | Periksa email/password; pastikan tidak ada spasi ekstra |
| Diarahkan ke Dashboard Warga | Akun Anda berstatus warga, bukan admin; hubungi petugas IT |
| Tidak menemukan tombol Keluar | Buka menu profil (avatar/nama) di sidebar |
| Lupa password | Gunakan **Lupa Password?** atau hubungi petugas IT |
