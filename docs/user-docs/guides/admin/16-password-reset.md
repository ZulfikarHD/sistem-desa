# Lupa Password (Reset Password) - Panduan Pengguna (Admin)

> **Kelompok Pengguna:** Admin / Petugas Desa
> **Urutan:** 15 dari 15 — Cara mereset password akun petugas desa melalui email.

## Apa itu Lupa Password?

Fitur ini membantu admin/petugas desa yang lupa password agar bisa membuat password baru melalui email, tanpa bantuan petugas IT.

## Cara Menggunakan

### Meminta tautan reset

1. Buka halaman **Masuk** (`/login`).
2. Klik tautan **Lupa Password?** di dekat field password.
3. Masukkan **email** akun admin Anda.
4. Klik **Kirim Tautan Reset Password**.
5. Periksa kotak masuk email Anda (dan folder spam jika perlu).

> 💡 **Tips:** Pastikan email yang dimasukkan sama dengan email akun admin yang terdaftar.

### Mengatur password baru

1. Buka tautan reset yang dikirim ke email (berlaku terbatas, sekitar **60 menit**).
2. Masukkan email Anda (jika belum terisi).
3. Isi **Password Baru** dan **Konfirmasi Password**.
4. Klik **Reset Password**.
5. Anda akan diarahkan ke halaman masuk — login dengan password baru.

## FAQ

**Q: Saya tidak menerima email reset?**
A: Periksa spam/junk, pastikan email benar, lalu coba kirim ulang. Jika tetap gagal, hubungi petugas IT.

**Q: Tautan reset sudah kadaluarsa?**
A: Minta tautan baru dari halaman Lupa Password. Tautan lama tidak bisa dipakai lagi.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Token/tautan tidak valid | Minta tautan reset baru; jangan pakai link lama |
| Gagal login setelah reset | Pastikan memakai password baru, bukan yang lama |
| Form menolak password baru | Ikuti aturan password (panjang/kekuatan minimum) |
