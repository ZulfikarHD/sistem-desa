# Dashboard Admin - Panduan Pengguna (Admin)

> **Kelompok Pengguna:** Admin / Petugas Desa
> **Urutan:** 2 dari 17 — Halaman utama setelah login; pantau semua antrean dari sini.

## Apa itu Dashboard Admin?

Halaman utama setelah petugas desa masuk. Dashboard menampilkan berapa banyak surat yang menunggu, sedang diproses, siap diambil, dan selesai bulan ini — lengkap dengan peringatan jika ada yang sudah terlalu lama.

## Cara Menggunakan

### Melihat kartu status

1. Masuk sebagai **admin**, Anda akan diarahkan ke **Dashboard Admin**.
2. Empat kartu di bagian atas:
   - **Menunggu Verifikasi** — pengajuan baru yang belum ditangani
   - **Sedang Diproses** — surat sedang disiapkan
   - **Siap Diambil** — menunggu warga datang
   - **Selesai Bulan Ini** — arsip bulan berjalan
3. Warna kartu:
   - Netral — semua aman
   - Kuning/amber — ada yang mulai tertunda
   - Merah — ada yang sangat mendesak / jadwal terlewat
4. Klik kartu untuk membuka halaman terkait.

### Menindaklanjuti yang mendesak

1. Jika ada bagian **Perlu Ditindaklanjuti Segera**, buka daftar tersebut.
2. Klik **Tangani** pada baris yang ingin dikerjakan.
3. Sistem mengarahkan ke halaman verifikasi, surat diproses, atau scan QR sesuai status.

### Tombol cepat

- **Verifikasi Pengajuan Baru** — ke daftar menunggu verifikasi
- **Proses Surat** — ke daftar surat diproses

> 💡 **Tips:** Jika semua kartu aktif bernilai 0, Anda akan melihat pesan bahwa tidak ada pengajuan yang perlu ditangani.

## FAQ

**Q: Mengapa kartu berwarna merah?**
A: Ada pengajuan yang melewati batas waktu (misalnya menunggu verifikasi lebih dari 7 hari, atau jadwal pengambilan sudah lewat).

**Q: Apakah angka diperbarui otomatis tanpa refresh?**
A: Angka dihitung ulang setiap kali halaman dibuka. Muat ulang halaman untuk data terbaru.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Tidak bisa membuka dashboard | Pastikan akun berrole admin dan sudah login |
| Kartu merah terus | Selesaikan item tertua di seksi "Perlu Ditindaklanjuti" |
