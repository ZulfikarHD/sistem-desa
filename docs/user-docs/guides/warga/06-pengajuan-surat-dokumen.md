# Unggah Dokumen Persyaratan - Panduan Pengguna (Warga)

> **Kelompok Pengguna:** Warga
> **Urutan:** 6 dari 12 — Cara mengunggah dokumen sesuai aturan jenis surat.

## Apa itu Unggah Dokumen Persyaratan?

Saat mengajukan surat, Anda melihat **daftar persyaratan** dengan badge yang menjelaskan cara memenuhinya. Tombol unggah hanya muncul untuk syarat yang bertanda **Wajib diunggah** atau **Boleh dikosongkan**. Syarat **Bawa ke kantor** dan **Informasi** tidak punya tombol unggah.

## Cara Menggunakan

### Mengunggah Dokumen pada Formulir Pengajuan

1. Buka halaman **Pengajuan Surat** (setelah masuk sebagai warga).
2. Pilih **Jenis Surat** — daftar persyaratan muncul dengan badge.
3. Untuk setiap syarat **unggah**, klik **Pilih file**. Nama kolom mengikuti nama syarat (misalnya *Fotokopi KTP*, *Slip gaji*).
4. Format yang diterima: **JPG, PNG, atau PDF**. Ukuran maksimum **2 MB** per file.
5. Periksa **pratinjau** di bawah kolom. Jika salah, klik **Hapus** lalu pilih ulang.
6. Isi **Keperluan**, lalu klik **Kirim Pengajuan**.

> 💡 **Tips:** Syarat **Bawa ke kantor** cukup disiapkan fisik; bawa saat diminta petugas / pengambilan. Syarat **Boleh dikosongkan** boleh dikirim tanpa file.

### Mengganti Jenis Surat

Jika Anda mengubah **Jenis Surat**, file yang sudah dipilih dihapus otomatis. Unggah ulang sesuai daftar baru.

## FAQ

**Q: Apakah semua jenis surat meminta unggah file?**
A: Tidak. Hanya syarat yang admin tandai “Unggah di aplikasi”.

**Q: Format apa yang didukung?**
A: JPG, PNG, dan PDF.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Pesan “Dokumen … wajib diunggah” | Unggah file untuk syarat berbadge **Wajib diunggah** |
| Pesan format / ukuran | Gunakan JPG/PNG/PDF maks. 2 MB |
| Tidak ada tombol unggah untuk suatu syarat | Badge-nya **Bawa ke kantor** atau **Informasi** — tidak perlu unggah |
| Area unggah tidak muncul sama sekali | Jenis surat hanya punya syarat non-unggah, atau belum dipilih |
