# Dashboard Warga - Panduan Pengguna (Warga)

> **Kelompok Pengguna:** Warga
> **Urutan:** 8 dari 12 — Pantau status surat Anda dari halaman utama.

## Apa itu Dashboard Warga?

Halaman pertama setelah Anda masuk sebagai warga. Fokus utamanya menjawab: **"Sudah sampai mana surat saya?"** — bukan halaman sapaan atau menu umum.

Judul besar di atas menampilkan **Status surat Anda** (atau ajakan mengajukan jika belum ada pengajuan aktif). Label kecil "Dashboard Warga" hanya penanda halaman.

## Cara Menggunakan

### Melihat status pengajuan aktif

1. Masuk dengan akun warga — Anda diarahkan ke **Dashboard Warga**.
2. Kartu besar di bagian atas menampilkan:
   - Jenis surat dan nomor pengajuan
   - Status saat ini (badge besar)
   - Alur singkat: **Diajukan → Diproses → Siap diambil** (langkah aktif ditandai)
   - Penjelasan singkat dalam bahasa sehari-hari
   - Berapa hari sudah di status tersebut
3. Jika status **Diproses** atau **Siap Diambil**, gunakan tombol **Unduh Surat**.
4. Jika **Siap Diambil**, perhatikan **jadwal pengambilan** (tanggal & jam kerja) yang ditampilkan besar — bawa KTP asli saat datang ke kantor desa.
5. Opsional: klik **Lihat detail** untuk halaman detail pengajuan.

### Jika belum ada pengajuan aktif

1. Anda akan melihat judul **Mulai pengajuan surat Anda**, pesan ramah, dan tombol **Ajukan Surat Sekarang**.
2. Klik tombol tersebut untuk mulai pengajuan. Panduan: [Pengajuan Surat](05-pengajuan-surat-form.md).

### Ajukan surat baru

1. Jika sudah ada pengajuan aktif, tombol **Ajukan Surat Baru** ada di bawah kartu status (dan juga di pojok kanan atas pada layar lebar).

### Riwayat dan notifikasi

1. Bagian **Riwayat Terbaru** menampilkan 3 pengajuan terakhir (jenis surat, nomor, status, tanggal). Ketuk baris untuk membuka detail. Klik **Lihat Semua Riwayat** untuk daftar lengkap.
2. Bagian **Notifikasi Terbaru** menampilkan 3 notifikasi (yang belum dibaca diutamakan). Titik merah = belum dibaca.
3. Jika ada notifikasi belum dibaca, banner kuning di atas memberi tahu jumlahnya — klik **Lihat notifikasi** atau **Lihat Semua Notifikasi** untuk membuka panel lonceng.

> 💡 **Tips:** Jika status masih "Diajukan" lebih dari seminggu, teks hari akan berwarna kuning sebagai pengingat untuk menghubungi kantor desa bila perlu.

## FAQ

**Q: Kenapa saya tidak melihat tombol unduh surat?**
A: Tombol unduh hanya muncul jika surat sudah digenerate (status Diproses / Siap Diambil / Selesai).

**Q: Bisa melihat pengajuan orang lain?**
A: Tidak. Dashboard hanya menampilkan data milik akun Anda.

**Q: Apa arti langkah di alur Diajukan → Diproses → Siap diambil?**
A: Itu ringkasan posisi surat Anda di proses desa. Langkah yang sedang aktif ditandai lebih tegas; langkah sebelumnya biasanya sudah ditandai selesai.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Banner notifikasi tidak hilang | Buka panel lonceng dan klik notifikasi agar ditandai dibaca |
| Jadwal pengambilan tidak muncul | Pastikan status sudah Siap Diambil; hubungi petugas jika tanggal belum diisi |
| Tidak menemukan Ajukan Surat Baru | Scroll sedikit di bawah kartu status, atau gunakan tombol di pojok kanan atas (layar lebar) |
