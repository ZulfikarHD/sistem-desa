# Manajemen Profil - Panduan Pengguna (Warga)

> **Kelompok Pengguna:** Warga
> **Urutan:** 2 dari 12 — Pastikan data Anda selalu benar sebelum mengajukan surat.

## Apa itu Manajemen Profil?

Halaman **Profil** dipakai warga untuk melihat dan memperbarui data kontak (nama, nomor telepon, alamat, email). NIK dan role ditampilkan tetapi **tidak bisa diubah sendiri**. Untuk mengganti password, gunakan menu **Keamanan**.

## Cara Menggunakan

### Melihat dan mengedit profil

1. Masuk ke sistem (login sebagai warga).
2. Buka menu akun di sidebar, lalu pilih **Pengaturan** (atau buka `/settings/profile`).
3. Di tab **Profil**, periksa data Anda:
   - **NIK** dan **Role** — hanya dibaca, tidak bisa diubah
   - **Nama**, **No. Telepon**, **Alamat**, **Email** — dapat diubah
4. Ubah field yang diperlukan.
5. Klik **Simpan**.
6. Pastikan muncul pesan sukses bahwa profil berhasil diperbarui.

> 💡 **Tips:** Data nama dan alamat yang benar penting karena akan tercetak di surat keterangan yang diterbitkan.

### Mengganti password

1. Dari halaman Pengaturan, buka tab **Keamanan**.
2. Jika diminta, masukkan password Anda saat ini untuk konfirmasi akses.
3. Isi form:
   - **Password Saat Ini**
   - **Password Baru**
   - **Konfirmasi Password Baru**
4. Klik **Simpan**.
5. Logout lalu login lagi dengan password baru untuk memastikan berhasil.

> 💡 **Tips:** Password baru harus memenuhi aturan keamanan (minimal panjang/karakter sesuai sistem).

## FAQ

**Q: Mengapa NIK saya tidak bisa diubah?**
A: NIK adalah identitas unik akun. Perubahan NIK hanya bisa dilakukan oleh petugas desa jika diperlukan.

**Q: Saya lupa password lama, bisa ganti di Keamanan?**
A: Tidak. Gunakan tautan **Lupa Password?** di halaman login. Panduan: [Lupa Password](03-password-reset.md).

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Tombol Simpan error pada telepon/alamat | Pastikan No. Telepon dan Alamat terisi |
| Gagal ganti password | Pastikan Password Saat Ini benar dan password baru dikonfirmasi sama |
| Tidak bisa buka Keamanan | Konfirmasi password terlebih dahulu jika sistem memintanya |
