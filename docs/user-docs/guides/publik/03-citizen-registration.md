# Registrasi Akun Warga - Panduan Pengguna

> **Kelompok Pengguna:** Publik / Tamu
> **Urutan:** 3 dari 3 — Buat akun agar bisa mengajukan surat.

## Apa itu Registrasi Akun Warga?

Fitur ini memungkinkan warga desa membuat akun sendiri agar bisa mengajukan surat keterangan secara daring. Anda mengisi data identitas (NIK, nama, kontak) dan password, lalu masuk melalui halaman login.

## Cara Menggunakan

### Mendaftar akun baru

1. Buka halaman **Registrasi** (`/register`), dari beranda klik **Daftar** / **Daftar sebagai Warga**, atau dari halaman login klik tautan **Daftar**.
2. Isi form:
   - **NIK**: 16 digit angka sesuai KTP (tidak boleh sama dengan akun lain)
   - **Nama**: nama lengkap
   - **No. Telepon**: nomor yang bisa dihubungi
   - **Alamat**: alamat lengkap sesuai KTP
   - **Email**: alamat email aktif (harus unik)
   - **Password** dan **Konfirmasi Password**: minimal sesuai aturan keamanan (biasanya 8 karakter)
3. Klik **Daftar**.
4. Jika berhasil, Anda akan diarahkan ke halaman **Login** dengan pesan sukses. Masuk memakai email dan password yang baru dibuat.

> 💡 **Tips:** Pastikan NIK dan email belum pernah dipakai mendaftar. Jika muncul error "sudah terdaftar", gunakan data lain atau hubungi petugas desa.

### Jika registrasi gagal

- **NIK bukan 16 digit** — periksa kembali angka NIK di KTP.
- **NIK / email sudah terdaftar** — akun mungkin sudah ada; coba login atau reset password.
- **Password tidak cocok** — pastikan konfirmasi password sama persis.

## FAQ

**Q: Apakah saya langsung masuk setelah daftar?**
A: Tidak. Setelah registrasi berhasil Anda diarahkan ke halaman login dan harus masuk manual.

**Q: Role akun saya apa?**
A: Akun baru selalu berstatus **warga**. Akun admin dibuat oleh petugas, bukan lewat form ini.

**Q: Bisakah saya mengubah NIK sendiri nanti?**
A: NIK tidak dimaksudkan untuk diubah sendiri oleh warga (akan diatur di manajemen profil).

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Form menolak NIK | Pastikan tepat 16 digit angka, tanpa spasi |
| Email ditolak | Gunakan format email valid yang belum terdaftar |
| Tidak ada pesan sukses | Pastikan semua field wajib terisi, lalu coba lagi |
| Lupa password setelah daftar | Gunakan tautan lupa password di halaman login |
